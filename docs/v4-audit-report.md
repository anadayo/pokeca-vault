# POKÉCA VAULT / OP CARD VAULT v4.0 監査レポート

更新日: 2026-10-12

## 正常に動作している項目

- 両サービスともカードマスターは200種類。
- ポケカとワンピカードの保存キーは分離され、既存の保有・売却履歴・アラートを維持する。
- GA4、メルカリアンバサダーURL共通生成、クリックログ、重複計測抑制を実装済み。
- 検索、レアリティ絞り込み、並び替え、保有登録、資産計算、ウォッチ、価格アラートを実装済み。
- データ品質条件を満たす静的相場ページを各100件生成し、canonical、BreadcrumbList、sitemapを出力。
- GitHub Actionsで価格を1日4回確認し、ワンピカード一覧を週1回再選定。

## 今回改善した項目

- 商品と価格を分離した共通JSONスキーマを追加。
- 未取得価格を0円ではなくnullとして扱い、取得元URL、取得方法、信頼度、最終結果を保存。
- 価格履歴は取得に成功した日だけ追加し、過去履歴を上書きせず最大366件保持。
- シード乱数による架空の365日価格履歴を削除。履歴不足時は「比較不可」「履歴蓄積中」と表示。
- 全角・半角、空白、ハイフン有無を吸収する検索と端末内検索履歴を追加。
- 買取価格順を両サービスの共通並び替えとして追加。
- 共通データ生成と検証を価格更新ワークフローに組み込み。

## 未実装または次フェーズ

- 複数店舗を横断した同一条件の販売・買取比較。現在は原則1取得元であり、その旨を表示している。
- 7日、30日、90日、1年ランキング。実測履歴が期間分蓄積したカードから自動表示される。
- 未開封BOX専用マスターとBOX価格履歴。
- Search Console実績に基づくタイトル・内部リンクの継続改善。
- サーバー側のユーザー同期、通知配信、複数端末同期。現在の資産データは端末内保存。

## データ方針

- 取得できなかった価格は前回値を画面上の現在値として維持できるが、その日付の履歴には追加しない。
- 複数店舗比較が未完了の値を「市場平均」「最安値」「最高値」と断定しない。
- 実データとシミュレーションを混在させない。
- 取得元、確認日、アフィリエイト表記をユーザーから確認できる状態にする。
